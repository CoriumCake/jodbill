# ⚡ jodbill (จดบิล) - ระบบบันทึกและคำนวณค่าน้ำค่าไฟอัจฉริยะ

เว็บแอปพลิเคชันสำหรับเด็กหอพัก คอนโด และบ้านอยู่อาศัย เพื่อใช้บันทึกและติดตามค่าน้ำ-ค่าไฟแบบ **Real-time Projection Dashboard** พร้อมระบบ **AI OCR อ่านเลขมิเตอร์จากภาพถ่ายอัตโนมัติ** และ **ส่งออกไฟล์ CSV/JSON**

---

## ✨ ฟีเจอร์หลัก (Key Features)

### 1. 📊 Real-Time Estimate & Burn Rate Dashboard
- **ประมาณการบิลสิ้นเดือน (Projected Month-end Bill):** คำนวณตามรอบตัดบิลจริงและอัตราการใช้ไฟ/น้ำในปัจจุบัน
- **อัตราการใช้พลังงาน (Burn Rate):** แสดงหน่วยต่อวัน, ค่าใช้จ่ายเฉลี่ยต่อวัน, และค่าใช้จ่ายต่อชั่วโมง (฿/hr)
- **มาตรวัดสไตล์หน้าปัดมิเตอร์ (Odometer Display):** แสดงเลขมิเตอร์ล่าสุดแยกหลักหน่วยและทศนิยมสีแดง
- **ระบบแจ้งเตือนงบประมาณ (Budget Gauge):** แสดงแถบเปรียบเทียบกับงบที่ตั้งไว้ (ปลอดภัย / ใกล้เกิน / เกินงบ)

### 2. 📸 AI OCR & Camera Meter Scanner (ระบบสแกนมิเตอร์)
- **เปิดกล้องถ่ายรูปได้โดยตรง:** พร้อมกรอบช่วยเล็งตัวเลขและปุ่มสลับกล้องหน้า/หลัง
- **อัปโหลดรูปภาพ / ลากวาง:** รองรับรูปถ่ายจากมือถือทุกรุ่น
- **การประมวลผล 2 ระดับ:**
  - **Client-Side OCR (Tesseract.js):** ทำงานในเครื่องได้ 100% ออฟไลน์ มีระบบปรับ Contrast ภาพให้อัตโนมัติ
  - **Google Gemini Multimodal AI Vision:** รองรับใส่ API Key เสริม เพื่ออ่านมิเตอร์ล้อหมุนเก่า มัว หรือมิเตอร์น้ำหน้าปัดซับซ้อนได้อย่างแม่นยำ 99%
- **ปุ่มปรับค่ารวดเร็ว (Quick Stepper):** `+0.1`, `+1.0`, `+5.0`, `+10.0` พร้อมคำนวณส่วนต่างหน่วยและค่าใช้จ่ายที่เพิ่มขึ้นทันทีก่อนกดยืนยัน

### 3. ❄️ Dorm Energy Simulator (เครื่องคำนวณจำลองค่าไฟแอร์และเครื่องใช้ไฟฟ้า)
- จำลองการเปิดใช้งานเครื่องใช้ไฟฟ้ายอดนิยมในหอพัก เช่น:
  - แอร์ Inverter (9,000 - 12,000 BTU)
  - แอร์ธรรมดา Fixed Speed
  - คอมพิวเตอร์เล่นเกม / ทำงาน
  - เครื่องทำน้ำอุ่น (3,500W)
  - ตู้เย็น, พัดลม, กาต้มน้ำร้อน, ไดร์เป่าผม, เตาแม่เหล็กไฟฟ้า
- ปรับสไลเดอร์ชั่วโมงการใช้งานต่อวัน เพื่อดูยอดเงินและหน่วยไฟฟ้าที่เพิ่มขึ้นต่อเดือนตามเรทหอพักของคุณ
- แนะนำเคล็ดลับการประหยัดไฟหอพัก

### 4. ⚙️ อัตราคิดราคาที่ยืดหยุ่น (Rate Configurations)
- **เรทหอพัก/คอนโด (Dorm Flat Rate):** กำหนดค่าไฟต่อหน่วย (เช่น 8 บาท), ค่าน้ำต่อหน่วย (เช่น 18 บาท), ค่าน้ำขั้นต่ำ, และค่าบริการห้องคงที่
- **เรทการไฟฟ้า MEA / PEA (Progressive Step Rate):** คำนวณอัตราก้าวหน้าประเภท 1.1 / 1.2 ของบ้านอยู่อาศัย + ค่า Ft + ค่าบริการ + VAT 7%

### 5. 📥 ส่งออกข้อมูล & ใบสรุปบิล (Export & Print Slip)
- **ส่งออกไฟล์ CSV:** สำหรับเปิดใน Microsoft Excel, Google Sheets, หรือ Apple Numbers โดยมี UTF-8 BOM รองรับภาษาไทย 100%
- **สำรองและกู้คืน (Backup JSON):** นำเข้า/ส่งออกข้อมูลทั้งหมดเพื่อย้ายเครื่องหรือบันทึกเก็บไว้
- **ใบแจ้งสรุปบิล (Print Slip):** สรุปยอดค่าน้ำค่าไฟสำหรับแชร์ให้รูมเมท หรือสั่งพิมพ์เป็น PDF

## 🚀 วิธีการติดตั้งและรันใช้งาน (Getting Started)

```bash
# ติดตั้ง dependencies
npm install

# รันเซิร์ฟเวอร์ Development (พอร์ต 5173)
npm run dev

# บิลด์สำหรับ Production
npm run build
```

เปิดเว็บเบราว์เซอร์ไปที่: `http://localhost:5173/`
